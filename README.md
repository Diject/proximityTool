# proximityTool

A mod for OpenMW that provides an API for tracking objects and displaying the distance to their nearest position in the game UI.  
It also includes a wrapper for creating HUD markers using HUDMarkers.

The mod displays the distance to the nearest tracked object both in the HUD and in the character menu.  
In the character menu, you can view all nearby tracked objects with the ability to scroll through them by simply dragging.  
Additionally, the mod allows you to customize many of its parameters, such as size, position, alignment, font size, and more.

There is an example of how to use the mod, which shows the nearest exit from an interior cell, [simple-exit-detector](https://github.com/Diject/simple-exit-detector).

## Requirements:
- OpenMW 0.49

## Installation:
Extract the files into the `Data Files` folder.
Or into any other folder, and then add the folder's path in the "Data Directories" tab of the launcher.
